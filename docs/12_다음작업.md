# 다음작업

이 문서는 다음 단계에서 진행할 작업 순서를 정리한 문서입니다.

## 권장 작업 순서

1. PDF 상태관리 기능 추가
2. PDF 매칭 검사 스크립트 보강
3. PDF 폴더 스캔
4. 엑셀 있음 + PDF 없음 항목 분류
5. PDF 있음 + 엑셀 없음 항목 분류
6. 파일명 불일치 항목 분류
7. PDF 내부 텍스트 기반 매칭 후보 분류
8. 중복 PDF 검사
9. PDF 5개 샘플 투입 테스트
10. 정상 확인 후 전체 PDF 투입

## PDF 상태관리에서 필요한 구분

- 엑셀 있음 + PDF 있음
- 엑셀 있음 + PDF 없음
- PDF 있음 + 엑셀 없음
- 파일명 정확 일치
- 파일명 정규화 기준 유사 일치
- PDF 내부 텍스트 기준 매칭 후보
- 중복 PDF 의심
- 한 제품에 여러 PDF 후보 존재
- 수동 확인 필요

## 테스트 순서

처음부터 전체 PDF를 넣지 말고, PDF 5개 정도만 먼저 `pdf/` 폴더에 넣어 검사합니다.

샘플 테스트에서 아래 항목을 확인합니다.

- 정확 파일명 매칭이 되는지
- 파일명이 달라도 내부 텍스트 기준 후보가 잡히는지
- PDF가 없는 제품이 `PDF 미등록`으로 분류되는지
- 엑셀에 없는 PDF가 `엑셀 미등록 PDF`로 분류되는지
- 중복 PDF 의심 항목이 자동 확정되지 않고 확인 필요로 남는지

샘플 테스트가 정상으로 확인된 뒤 전체 PDF를 투입합니다.
