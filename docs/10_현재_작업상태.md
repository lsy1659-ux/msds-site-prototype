## 데이터 읽기 순서

사이트는 local 파일이 있으면 local 데이터를 우선하고, 없으면 public 데이터를 읽습니다.

1. `data/msds.local.json`
2. `data/msds.public.json`
3. 샘플 또는 화면 내 fallback 데이터

override도 같은 방식으로 local, public, sample 순서로 읽습니다.

## 로컬 실행

비개발자는 저장소의 `start_msds_site.bat`를 더블클릭합니다. 직접 실행할 때는 저장소에서 로컬 서버를 열고 `http://localhost:8000/`으로 접속합니다.

## 주의사항

- 등록대장 엑셀은 참고·대조용이며 사이트 데이터를 통째로 덮어쓰지 않습니다.
- 원본 엑셀, local JSON, 백업, local 점검 리포트는 GitHub에 올리지 않습니다.
- GitHub Pages 운영에 필요한 public JSON과 `pdf/` 대표 PDF는 저장소에서 관리할 수 있습니다.
