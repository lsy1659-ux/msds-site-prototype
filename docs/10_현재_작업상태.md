# 현재 작업상태

이 문서는 새 Codex 대화나 사람이 직접 작업을 이어갈 때 현재 상태를 빠르게 확인하기 위한 인계 문서입니다.

## 현재 완료된 작업

- MSDS 현장 조회사이트 프로토타입 생성 완료
- 현장 작업자가 QR코드로 접속해 빠르게 검색하는 조회용 화면 구성 완료
- 전체 제품 목록을 처음부터 길게 보여주지 않는 검색 중심 UI 적용 완료
- 좌측 현장 부착용 요약판, 우측 상세정보, 성분정보, PDF 미리보기 구조 구성 완료
- 샘플 데이터 기반 기본 화면 구성 완료
- 엑셀 데이터를 검색용 JSON으로 변환하는 구조 준비 완료
- 실제 엑셀 변환 테스트 성공

## 변환 확인 결과

- 제품 176개 변환 성공
- 성분정보 1,396개 변환 성공
- 변환 결과 파일은 `data/msds.local.json`
- `data/msds.local.json`은 로컬 전용 파일이며 GitHub 제외 대상
- 실제 엑셀 원본은 `data/raw/` 안에서만 사용하며 GitHub 제외 대상

## 현재 데이터 모드

현재 확인된 모드는 `로컬 변환 데이터 모드`입니다.

사이트는 먼저 `data/msds.local.json`을 읽고, 실패하면 `data/msds-sample.json` 또는 `js/app.js`의 fallback 샘플 데이터로 동작합니다.

## 현재 로컬 서버 실행 방법

저장소 폴더에서 아래 명령으로 로컬 서버를 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8000/
```

Python 명령이 바로 실행되지 않는 환경에서는 Codex 런타임의 Python 또는 GitHub Desktop/터미널에서 사용 가능한 Python을 사용합니다.

## 주의사항

- 실제 회사 엑셀 원본은 GitHub에 올리지 않습니다.
- 실제 MSDS PDF는 GitHub에 올리지 않습니다.
- `data/msds.local.json`은 실제 제품정보가 들어갈 수 있으므로 GitHub에 올리지 않습니다.
- PDF 매칭 리포트도 실제 제품명/PDF 정보가 들어갈 수 있으므로 GitHub에 올리지 않습니다.
