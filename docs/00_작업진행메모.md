# 00. 작업진행메모

이 문서는 MSDS 조회 사이트의 실제 작업 상태를 누적 기록하는 인계 메모입니다. 작업이 끝날 때마다 함께 갱신합니다.

## 1. 지금까지 완료한 작업

### 2026-07-17 PC·모바일 MSDS 미리보기 정리

- PC와 모바일에서 `PDF 다운로드` 버튼만 제거하고 기존 `원본 PDF 열기`, `PDF 미리보기`, `전체화면 미리보기` 버튼은 유지했습니다.
- 자동 추출 요약이 있는 제품에 표시되던 `자동 추출 요약` 상태 배지는 검색 카드·전체 목록·선택 제품 상단에서 숨겼습니다.
- PDF 원문 확인이 필요한 제품의 경고 배지는 안전상 계속 표시합니다.
- PC와 모바일 모두 `PDF 미리보기`를 누르면 사이트 내부 PDF 영역으로 이동해 미리보기가 열리고, `전체화면 미리보기`도 별도로 사용할 수 있습니다.
- 모바일 브라우저의 PDF 프레임 호환 문제를 피하기 위해 PDF.js 페이지 렌더링 방식을 복원했습니다.
- 1280×720 PC와 390×844 모바일 화면에서 KR-3000을 검색해 미리보기 첫 페이지가 정상 표시되는 것을 확인했습니다.
- 화면에서 다운로드 버튼 0개와 자동 추출 상태 배지 0개를 확인했습니다.
- 자동검사 25건과 공개 배포 검증을 모두 통과했습니다.

### 2026-07-16 최신 PDF 반영 및 사이트 품질 점검

- 회사 최신 원본 폴더 `00_ 캠스 MSDS`를 기준으로 노루오토코팅 PDF 8개를 최신본으로 교체했습니다.
- 교체 전 PDF와 local 데이터는 `data/backups/20260716_pre_noroo_update/`에 백업했습니다.
- `2026 캠스 MSDS 등록대장_20260630_SG3200001최신반영.xlsx`는 참고·대조용으로만 읽었으며 사이트 데이터를 통째로 덮어쓰지 않았습니다.
- 업데이트 이력과 PDF 원문을 대조해 해당 제품을 선택적으로 갱신했습니다.
- 최신 8개 PDF의 개정일, CAS No., 함유량, GHS 그림문자, 유해·위험문구를 전문 대조했고 모두 통과했습니다.
- 노루오토코팅 공급자명이 `/유통업자 정보`로 잘못 추출되던 문제를 `(주)노루오토코팅`으로 정정했습니다.
- 개정일 추출 시 최초 작성일을 잘못 쓰지 않도록 최종 개정일 우선 규칙을 보강했습니다.
- `0.1∼0.6` 같은 함유량 범위와 줄바꿈된 성분명/CAS를 정확히 분리하도록 PDF 추출 규칙을 보강했습니다.
- 화면에 보이는 제품명·성분명의 확인 가능한 영문을 한글로 바꾸고, `Acrliyc`, `arcrylate`, `PRIMIER`, `CAMS 용`, `블스원`, `코광택` 등의 오타를 정리했습니다.
- 긴 중합체명이나 고유 IUPAC명처럼 검증된 한글명이 없는 영문은 오역 위험 때문에 원문을 유지했습니다.
- SHA-256이 완전히 같은 중복 PDF 15개를 별도 백업한 뒤 대표본 하나만 남겼습니다.
- 중복 제품 9개와 중복 override 12개를 대표 항목으로 통합했습니다.
- `PUB795101 (KR).pdf`에 중복 등록된 제품 레코드 2개가 내용과 ID만 다른 완전 중복임을 확인해 기존 ID `msds-013` 하나만 남겼습니다.
- 최신 8개 모두 등록대장의 직전 개정일이 최초 작성일로 잘못 들어간 문제를 발견해 PDF 원문 기준 최초 작성일과 최종 개정일로 바로잡았습니다.
- 현재 제품 223개, 실제 MSDS PDF 223개가 1:1로 연결됩니다. 전체 PDF 224개 중 나머지 1개는 QR코드 안내문입니다.
- PDF 누락 0개, 완전 중복 0개, 동명 파일 중복 0개, 여러 후보 제품 0개입니다.
- MSDS가 아닌 `0. 캠스 MSDS QR 코드.pdf` 1개만 제품 등록 대상에서 제외 상태로 유지합니다.
- 공개용 `data/msds.public.json`을 제품 223개 기준으로 다시 생성했습니다. override 224개 중 1개는 제외된 QR코드 안내문 기록입니다.
- 최신 `SG3200001`을 실제 화면에서 검색해 개정일 `2026-06-25`, 큐멘 `98-82-8 / 0.1~0.6`, 한글 성분명, 위험·예방 문구를 확인했습니다.
- PC와 휴대폰 폭에서 화면 넘침이 없고, 38쪽 PDF 미리보기가 열리며 브라우저 오류 로그가 0건인 것을 확인했습니다.

## 2. 현재 프로젝트 구조

```text
msds-site-prototype
├─ index.html                 현장 조회 화면
├─ review.html                내부 PDF 추출 검토 화면
├─ pdf-queue.html             엑셀 미등록 PDF 검토 화면
├─ data
│  ├─ msds.public.json        GitHub Pages 공개 제품 데이터 223개
│  ├─ msds-overrides.public.json
│  ├─ msds.local.json         로컬 실사용 제품 데이터 223개
│  ├─ msds-overrides.local.json
│  └─ backups                 교체·중복 정리 전 백업
├─ pdf                        대표 MSDS 223개 + QR 안내문 1개
├─ reports                    로컬 점검 리포트
├─ scripts                    변환·추출·점검·중복 정리 도구
└─ docs                       운영 및 인계 문서
```

## 3. 다음에 해야 할 작업

- PC·모바일 미리보기 변경은 `main`에 푸시했고 GitHub Pages 공개 반영을 확인했습니다.
- 다음 자료 갱신 때 공개 주소에서 `SG3200001`, `PGE008002`, `PUB795101` 검색과 PDF 미리보기를 다시 확인합니다.
- 기존 PDF 추출 후보 중 `검토필요` 209개는 원본 PDF와 순차 대조합니다.
- 최초 작성일이 비어 있는 18개는 원본에 날짜가 실제로 있는지 별도 확인합니다.
- 내용 유사 후보 18그룹은 완전 중복이 아니므로 버전과 제품 차이를 사람이 확인하기 전까지 삭제하지 않습니다.

## 4. 초보자가 기억해야 할 주의사항

- 회사 최신 원본 폴더가 PDF의 기준이며, 사이트 `pdf/`는 공개·조회용 대표본입니다.
- 등록대장 엑셀은 참고·비교·문제 분석용입니다. 엑셀 전체를 사이트 데이터 위에 그대로 덮어쓰지 않습니다.
- 최신 PDF를 바꾸기 전에는 반드시 기존 PDF와 local JSON을 백업합니다.
- 같은 파일명이라도 내용이 다를 수 있으므로 해시와 PDF 본문을 함께 확인합니다.
- 완전 중복 삭제는 SHA-256이 같은 경우에만 대표본을 정하고 백업 후 진행합니다.
- 제품명이 비슷하거나 성분이 비슷한 것만으로는 파일을 삭제하지 않습니다.
- 공개 데이터는 `build_public_data.py`로 다시 만든 뒤 화면에서 검색과 PDF 미리보기를 확인합니다.
- local JSON, 원본 엑셀, 점검 리포트와 백업은 GitHub에 올리지 않습니다.

## 5. 마지막으로 실행한 지시문 요약

사용자는 기존 PDF 보기 버튼은 유지하고 `PDF 다운로드` 버튼만 없애며, 자동 추출 요약 상태 네모 표시를 숨기고 모바일에서도 PC처럼 MSDS 미리보기가 정상적으로 보이도록 요청했습니다.
