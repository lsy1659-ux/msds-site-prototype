# 운영원칙

이 문서는 MSDS 현장 조회사이트를 운영형 구조로 확장할 때 반드시 지켜야 할 기준입니다.

## 기본 원칙

- 엑셀은 전체 제품 검색용 색인으로 사용합니다.
- PDF는 있는 것만 연결합니다.
- PDF가 없는 제품도 검색 가능해야 합니다.
- PDF가 없는 제품은 화면과 리포트에서 `PDF 미등록`으로 표시합니다.
- 엑셀보다 PDF 원본이 더 많을 수 있습니다.
- PDF는 있는데 엑셀에 없는 경우 `엑셀 미등록 PDF`로 분류합니다.

## PDF 매칭 원칙

- PDF 파일명만으로 최종 판단하지 않습니다.
- 파일명이 달라도 PDF 내부 제품명, 물질명, CAS No.가 엑셀 데이터와 같으면 매칭 후보로 봅니다.
- 같은 MSDS PDF가 파일명만 다르게 중복 저장되어 있을 수 있으므로 중복 PDF 가능성을 고려합니다.
- 파일명 유사 매칭, 내부 텍스트 매칭, 중복 의심 PDF는 자동 확정하지 않습니다.
- 자동 판단이 애매한 항목은 `확인 필요` 리포트로 분류합니다.
- 스크립트는 PDF를 삭제, 이동, 이름 변경하지 않습니다.

## GitHub 업로드 금지 대상

아래 파일과 폴더는 실제 회사 정보가 들어갈 수 있으므로 GitHub에 올리지 않습니다.

- 실제 엑셀 원본
- 실제 MSDS PDF
- `data/msds.local.json`
- `data/*.local.json`
- `data/raw/`
- `data/original/`
- `reports/*.local.json`
- `reports/*.local.csv`
- 로컬 PDF 매칭 리포트

## 표시 기준

- 현장 조회 화면은 제품 검색과 핵심 안전정보 확인을 우선합니다.
- 관리자용 등록/수정/검토 기능은 현재 범위가 아닙니다.
- 불확실한 매칭 결과는 자동 연결하지 않고 사람이 확인할 수 있게 남깁니다.
