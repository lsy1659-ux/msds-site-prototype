# 현장용 로컬 실행 가이드

## 실행 방법

현장 검색용 화면은 프로젝트 폴더의 `start_msds_site.bat` 파일을 더블클릭해서 실행합니다.

더블클릭하면 브라우저가 자동으로 열리고 `index.html` 화면이 표시됩니다. 함께 열린 검은색 창은 로컬 실행을 유지하는 창입니다. MSDS 사이트를 사용하는 동안 닫지 말고 그대로 둡니다.

사용을 끝낼 때는 브라우저 탭을 닫고, 검은색 창도 닫으면 됩니다.

## 화면 용도

`index.html`은 현장 검색용 화면입니다. 현장에서 제품명, 파일명, CAS No. 등을 검색해 MSDS 요약과 PDF를 확인하는 용도입니다.

`review.html`은 검토 및 관리용 화면입니다. PDF 추출 후보, 검토 상태, 보정 후보를 확인하는 관리 목적 화면입니다. 현장 검색만 할 때는 `review.html`을 열 필요가 없습니다.

검토 및 관리용 화면은 `start_msds_review.bat` 파일을 더블클릭해서 실행합니다.

## Python이나 PowerShell을 몰라도 됩니다

사용자는 Python이나 PowerShell 명령을 직접 입력할 필요가 없습니다. `start_msds_site.bat` 또는 `start_msds_review.bat` 파일만 더블클릭하면 됩니다.

내부적으로는 Windows 기본 PowerShell을 사용해 이 프로젝트 폴더를 임시 로컬 서버처럼 열어 줍니다. 이 방식은 `data/msds.local.json` 같은 검색 데이터와 `pdf` 폴더의 PDF 파일을 브라우저가 안정적으로 읽기 위해 필요합니다.

## 데이터 로딩 기준

현장 검색용 `index.html`은 아래 순서로 데이터를 읽습니다.

1. `data/msds.local.json`
2. `data/msds.public.json`
3. `data/msds-sample.json`

보정 데이터도 아래 순서로 읽습니다.

1. `data/msds-overrides.local.json`
2. `data/msds-overrides.public.json`
3. `data/msds-overrides.sample.json`

집 PC 로컬 실행에서는 local JSON이 있으면 local 데이터를 우선 사용합니다. GitHub Pages 공개 화면에서는 local JSON이 없으므로 public JSON을 사용합니다. sample 데이터는 local/public 데이터가 없을 때의 fallback 용도입니다.

GitHub Pages 실제 MSDS PDF 미리보기 공개 운영은 완료되었습니다. 공개 URL은 <https://lsy1659-ux.github.io/msds-site-prototype/> 이며, 공개 화면에서는 `data/msds.public.json`, `data/msds-overrides.public.json`, `pdf/` 폴더의 PDF 239개를 사용합니다.

로컬 실행도 계속 가능합니다. 로컬 PC에 `data/msds.local.json`, `data/msds-overrides.local.json`이 있으면 공개용 데이터보다 local 데이터를 먼저 사용합니다. 실제 엑셀, `data/raw/`, `data/original/`, `.env`, local JSON, reports local 파일은 계속 비공개로 유지합니다.

모바일 자동 다운로드를 줄이기 위해 PDF는 제품 선택 직후 자동으로 열리지 않습니다. PDF 영역의 `PDF 미리보기` 버튼을 누르면 PDF.js가 전체 페이지를 세로로 렌더링하고, 같은 영역 안에서 스크롤로 확인할 수 있습니다. 확대, 축소, 폭맞춤도 사용할 수 있습니다. 현재 PDF.js는 CDN을 사용하므로 미리보기에는 인터넷 연결이 필요할 수 있습니다.

## 왜 HTML 파일을 직접 열지 않나요?

`index.html`이나 `review.html`을 직접 더블클릭하면 브라우저 주소가 `file://`로 시작할 수 있습니다. 이 경우 브라우저 보안 정책 때문에 `data/msds.local.json`, `data/msds-overrides.local.json` 같은 local JSON 파일을 읽지 못하거나 PDF 연결 상태 확인이 제대로 되지 않을 수 있습니다.

따라서 현장 사용은 `start_msds_site.bat` 실행을 기준으로 합니다.

## 실행이 안 될 때 확인할 것

1. 프로젝트 폴더 위치가 맞는지 확인합니다.
2. `start_msds_site.bat` 파일을 프로젝트 루트에서 실행했는지 확인합니다.
3. 실행 후 열린 검은색 창을 닫지 않았는지 확인합니다.
4. 회사 보안 정책으로 PowerShell 실행이 막혀 있지 않은지 확인합니다.
5. 브라우저 주소가 `http://127.0.0.1:`로 시작하는지 확인합니다.

## 검색 데이터가 안 뜰 때 확인할 것

로컬 운영 데이터는 local JSON 파일에서 우선 읽습니다. 아래 파일이 없으면 public JSON 또는 sample 데이터로 넘어갑니다.

- `data/msds.local.json`
- `data/msds-overrides.local.json`

이 local 파일들은 GitHub에 올리지 않는 로컬 전용 파일입니다. 공개용 화면에 반영하려면 집 PC에서 public JSON을 생성한 뒤 커밋합니다.

```powershell
python scripts/build_public_data.py
```

## PDF가 안 열릴 때 확인할 것

PDF는 프로젝트의 `pdf` 폴더를 기준으로 연결됩니다. PDF가 안 열리면 아래를 확인합니다.

1. 실제 PDF 파일이 `pdf` 폴더 안에 있는지 확인합니다.
2. PDF 파일명과 local JSON에 기록된 파일명이 맞는지 확인합니다.
3. 브라우저 주소가 `file://`가 아니라 `http://127.0.0.1:`로 시작하는지 확인합니다.
4. `start_msds_site.bat` 실행 창이 열려 있는지 확인합니다.

새 PDF는 정식 PDF 폴더에 바로 섞지 말고 `incoming` 폴더에 넣은 뒤 점검 스크립트로 확인합니다.
